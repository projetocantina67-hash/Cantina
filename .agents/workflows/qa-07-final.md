# QA 07 — Auditoria Final e Preparação para Banca

Descrição: Consolidar a auditoria e preparar a equipe para defender o projeto.

## Passos
1. Cruze todos os estados consolidados e relatórios.
2. Explique o que o sistema já implementa e o fluxo completo usuário → API → banco → resposta.
3. Consolide bugs sem duplicação e classifique por severidade.
4. Separe bugs, riscos, regras não definidas e melhorias.
5. Avalie se o backend está pronto para iniciar o React e justifique.
6. Liste os principais conceitos de Java, Spring Boot, JPA/Hibernate, REST, banco e Engenharia de Software presentes no projeto.
7. Para cada conceito importante, explique usando o código real.
8. Crie pelo menos 30 perguntas de banca, divididas em fácil, intermediário, difícil e perguntas que testem se a equipe realmente entende o código.
9. Para cada pergunta, dê uma resposta oral curta e uma explicação aprofundada.
10. Crie um plano de estudo por prioridade.
11. Não modifique código.
12. Gere `docs/qa/07-auditoria-final.md`.
13. Quando o mesmo problema aparecer em diferentes fases, mantenha o mesmo ID QA e consolide as evidências, evitando duplicação.
14. Finalize classificando o backend: Não pronto | Parcialmente pronto | Pronto com ressalvas | Pronto para frontend.
