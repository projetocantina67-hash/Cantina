# QA 04 — Controllers e API REST

Descrição: Auditar a API que futuramente será consumida pelo React.

## Passos
1. Use os estados consolidados anteriores.
2. Mapeie todos os endpoints, métodos HTTP, URLs, parâmetros, bodies, respostas e status codes.
3. Analise DTOs, validações, tratamento de exceções e mensagens de erro.
4. Verifique semântica de GET/POST/PUT/PATCH/DELETE.
5. Teste mentalmente payloads incompletos, IDs inexistentes, valores inválidos, duplicidade e erros de negócio.
6. Analise CORS, JSON, datas, horários, status HTTP e consistência dos contratos para o futuro React.
7. Explique REST, HTTP, JSON, DTO, Controller, MVC e separação de responsabilidades usando o projeto real.
8. Não altere código.
9. Gere `docs/qa/04-controller-api.md`.
10. Finalize com `ESTADO CONSOLIDADO — V4`.
