# QA 06 — Engenharia de Software e Aprendizado

Descrição: Transformar a auditoria técnica em material de estudo.

## Passos
1. Utilize todos os estados consolidados.
2. Analise arquitetura em camadas, separação de responsabilidades, coesão, acoplamento e modularização.
3. Analise POO: encapsulamento, abstração, herança, polimorfismo, interfaces e composição quando aplicável.
4. Analise SOLID sem forçar princípios que não estejam presentes.
5. Analise MVC, Repository Pattern, DTO, Service Layer, Dependency Injection e Inversion of Control.
6. Para cada conceito importante, explique: o que é, para que serve, onde aparece, como funciona, problema que resolve, alternativas, vantagens, desvantagens e como explicar ao professor.
7. Relacione conceitos entre si; não faça apenas um glossário.
8. Para conceitos arquiteturais relevantes, explique também quando não seria adequado utilizá-los ou quais alternativas poderiam ser adotadas.
9. Crie perguntas de professor com resposta curta e explicação aprofundada.
10. Crie um mapa de conhecimento: Java → Spring → persistência → API → Engenharia de Software → integração React.
11. Gere `docs/qa/06-engenharia-software.md`.
12. Finalize com `ESTADO CONSOLIDADO — V6`.
